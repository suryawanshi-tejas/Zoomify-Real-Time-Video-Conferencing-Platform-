# Zoom – Full-Stack Video Conferencing Application

A full-stack video conferencing web application that enables real-time video and audio communication between users.

- Developed a video conferencing platform using React.js, Node.js, Express.js, Socket.IO, and WebRTC.
- Implemented real-time audio/video communication and peer-to-peer connectivity using WebRTC.
- Integrated Socket.IO for real-time signaling and communication between participants.
- Built a responsive user interface for seamless online meetings and collaboration.
- Designed the application to support virtual meetings and real-time communication.
